# 🎨 `auracss`

> **AuraCSS** - The ultimate 70-theme visual CSS vault for instant zero-config website styling.

---

## 🚀 Quick Start

### 1. Installation
```bash
npm install auracss
```

### 2. Import CSS in your App
```javascript
// Import master stylesheet (HTML, React, Next.js, Vue, Vite)
import 'auracss';
```

### 3. Apply Theme via Attribute
```html
<!-- Whole website becomes Agentic AI style -->
<html data-theme="agentic">
  <body>
    <div class="theme-card">
      <h2>Title</h2>
      <button class="theme-btn">Action Button</button>
    </div>
  </body>
</html>
```

## 🛠 Available Semantic Components

Use these universal class names in your HTML/JSX code. They adapt instantly to whichever `data-theme` is set:

- `.theme-card` - Container card with theme surface & shadow
- `.theme-btn` - Primary button with hover transitions
- `.theme-btn-secondary` - Secondary button variant
- `.theme-input` - Text input field with focus ring
- `.theme-badge` - Tag / status indicator pill
- `.theme-nav` - Top navigation bar header
